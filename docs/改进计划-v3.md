## 0. 目标

1. **专注模式更"沉浸"**：表盘占满约 3/4 屏幕，右侧留出名言/激励语区域，专注时不再是一片空旷
2. **时间可视化**：圆环随时间**由暖转深**（颜色 + 光晕强度一起变），不用看数字也能感知"快结束了"
3. **日历不再孤立**：能直接看到"今天正在专注"，能从日历跳到日记、开始专注，反过来日记状态也显示在格子上

## 2. 专注模式重排

### 2.1 布局

```
┌──────────────────────────────────────────────────────────────┐
│  header：任务 chip                              [全屏] [退出] │
│                                                              │
│   ┌───────────────────────────┐   ┌──────────────────────┐   │
│   │                           │   │  今日                         │
│   │        大表盘              │   │  ▮▮▮▯  3 / 4 个番茄          │
│   │      （约 78% 屏高）        │   │                              │
│   │                           │   │  「一句名言，           │   │
│   │                           │   │    两行放得下最好」      │   │
│   │                           │   │        —— 作者            │   │
│   └───────────────────────────┘   │  ● ○ ○ ○   ← 轮播指示     │   │
│                                   └──────────────────────┘   │
│         [暂停] [5 分] [跳过] [放弃]                           │
│   Esc 退出 · Space 暂停 · F 全屏                              │
└──────────────────────────────────────────────────────────────┘
```

- 容器：`grid`，左侧 `1fr`，右侧固定 `360px`
- 窄屏（< 1100px）或窗口变矮：改为上下堆叠，名言区移到表盘下方并切 `compact` 样式
- 表盘尺寸：`clamp(320, min(视口宽 × 0.62, 视口高 × 0.78), 860)`
  - 用 `useDialSize` 同时监听 `resize`，按宽高取小值，避免竖屏溢出
- 按钮组、快捷键提示保持现状，整体下移贴近底部

### 2.2 表盘颜色随进度变化

设 `p = 已用时长 / 总时长`（0 → 1，空闲时 p = 0）：

| p | 主色 | 含义 |
| --- | --- | --- |
| 0 – 0.35 | `#e8674c` 珊瑚红（accent） | 刚开始 |
| 0.35 – 0.7 | 渐变到 `#f08a3c` 琥珀 | 进行中 |
| 0.7 – 0.92 | 渐变到 `#e0452f` 深橙红 | 过半，开始收尾 |
| 0.92 – 1 | `#d02b1f` 深红 + 光晕最强 | 最后冲刺 |

实现要点：

- 用 HSL 插值（色相 12° → 28° → 8° → 355°，饱和度 72% → 88%，亮度 60% → 48%）
- 同一颜色应用到：进度弧、已点亮的刻度、中心数字的轻微色偏（可选）、外发光
- **光晕强度**：`0.18 + 0.5 × p`，仅在大表盘（`glow` 为 true）时渲染
- 过渡 `transition: stroke 1s linear, filter 1s linear`，不要跳变
- 休息态（short/long break）保持青绿 `#5aa9a0` 不参与渐变
- **小表盘（今天页卡片，px=260）也复用颜色逻辑**，但不渲染光晕

### 2.3 右侧信息区

- 顶部：今日进度 `▮▮▮▯`（已完成 / 长休息间隔）+ 今日番茄数
- 中部：名言卡片（见 §3）
- 底部：`今天 X 个番茄 · Y 小时`（沿用现有数据）

## 3. 名言轮播

### 3.1 数据

本地静态数据，**不联网**。文件 `src/features/quotes/quotes.ts`：

```ts
export interface Quote {
  text: string;    // 控制在 40 字以内，两行放得下
  author: string;  // 如「鲁迅」「卡尔·纽波特」
  tag?: "focus" | "persist" | "calm";  // 可选，用于按阶段选句
}
export const QUOTES: Quote[];   // 建议 30 条左右
```

选句要求：

- 中外混合，出处准确（不确定出处的宁可不收，别编"爱因斯坦说"）
- 主题围绕：专注、坚持、时间、慢下来
- 单条 ≤ 40 字，超过的在数据里就截断或换一条

### 3.2 组件契约

```ts
// src/features/quotes/QuoteRotator.tsx
export default function QuoteRotator(props: {
  /** 紧凑模式：字号更小、指示点更少、不显示作者行内边距 */
  compact?: boolean;
  /** 轮播间隔，默认 12000ms */
  intervalMs?: number;
  className?: string;
}): JSX.Element;
```

行为：

- 每 `intervalMs` 换一条，切换动画 400ms：旧句淡出上移 6px，新句淡入
- 鼠标悬停时暂停轮播（离开后继续，计时重置）
- 底部指示点：最多 5 个（代表最近 5 条的状态，当前高亮）
- 「按专注阶段选句」：可选增强——收到 `phase`（`"start" | "middle" | "end"`）时优先从 `tag` 匹配的句子中挑；**本轮可只做纯随机且不重复**
- 严格遵守 `prefers-reduced-motion`（不做位移，直接替换）
- 不引入依赖；中文引号排版用全角

## 4. 日历联动

### 4.1 格子状态（CalendarPage）

| 元素 | 之前 | 现在 |
| --- | --- | --- |
| 热力条 | 底部 3px 色条 | 不变 |
| 心情点 | 右上 1.5px | 不变 |
| 日记标记 | 右下 2px 短竖线 | 改为小圆点：**草稿=空心描边**、**已归档=实心** |
| 正在专注 | 无 | 今天且计时器处于 running/paused 时，格子左上角加一个**呼吸脉冲点**（accent，2.5px，1.6s 循环） |
| 悬停 | 无 | 自定义 tooltip（见 4.2） |

### 4.2 悬停预览

鼠标停在格子上 180ms 后浮出小卡片：

```
11月17日 周二
专注 2h 15m · 3 个番茄
心情 🙂 不错
日记 已归档 / 草稿 / 无
```

- 用绝对定位 + `pointer-events-none`，靠近视口边缘时自动翻转方向（上/下）
- 只显示已有数据，空数据行隐藏

### 4.3 详情面板新增

选中某天后，右栏追加：

1. **开心度 mini 仪表**（复用 `HappinessGauge`，`size=96`，`animate=false`，静态度量）
2. **操作行**（按钮随状态变化）：
   - 今天：`开始专注`（primary，调用 `useTimer.startWork()`）、`查看日记`
   - 过去：`写日记` / `继续编辑` / `查看档案`（按 `day_entry.status` 切换文案）
   - 未来：只显示「这天还没到」，禁用操作
3. 已有的心情选择、记录列表、日记摘要保持不变

### 4.4 与日记的双向跳转

- 日历 → 日记：已有铅笔按钮，保留；新增「查看档案」直达 `/journal/:date`
- 日记 → 日历：日记页返回按钮改为「回日历」，携带 `?date=`，日历打开时若 URL 有 `date` 参数则选中该天（`useSearchParams`）

## 5. 动效规范（增量）

| 场景 | 时长 / 曲线 |
| --- | --- |
| 表盘颜色跳变 | 1000ms linear（`stroke` + `filter`） |
| 脉冲点呼吸 | 1600ms ease-in-out infinite（opacity 0.35 ↔ 1） |
| 名言切换 | 400ms `cubic-bezier(.16,1,.3,1)`，位移 ≤ 6px |
| Tooltip 出现 | 160ms ease-out，透明度 + 4px 位移 |
| 详情面板操作行 | 沿用现有 200ms |

全部受 `prefers-reduced-motion` 控制。
