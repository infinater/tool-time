## 0. 一句话目标

把「记录」升级成「可回看的情绪曲线」：每次番茄都能记心情，心情有权重、能算出开心度并可视化；日记从「编辑框」变成「写→归档→档案」的完整流程；删除可撤销、数据可整理；动效覆盖关键状态变化。

---

## 1. 现状与问题

| # | 现状 | 问题 |
| --- | --- | --- |
| 1 | 心情只存在 `day_entry.mood`，一天一个 | 同一小时里「很专注很开心」和「摸鱼很难受」被平均成一个值 |
| 2 | 心情只是 emoji/色环，没有权重概念 | 无法回答「这周整体开心吗」 |
| 3 | 日记只有编辑态，自动保存 | 没有「写完了」的完成感；回看时和编辑时长得一样 |
| 4 | 删除只能一条条删，且不可撤销 | 误删无法恢复；没有批量整理入口 |
| 5 | 动效集中在计时器 | 心情变化、归档、删除这些「有因果」的动作反而没有动画 |

## 3. 开心度（Happiness Index）

### 3.1 心情分值

| 心情 | 值 | 分值 `score` |
| --- | --- | --- |
| 很糟 | 1 | -1.0 |
| 低落 | 2 | -0.5 |
| 一般 | 3 | 0 |
| 不错 | 4 | +0.5 |
| 很好 | 5 | +1.0 |

### 3.2 权重

- **每次专注**：`weight = clamp(实际分钟 / 25, 0.5, 2)` —— 25 分钟 = 1.0，50 分钟封顶 2.0，5 分钟地板 0.5
- **只有日心情、没有 session 心情**：`weight = 1.0`
- 同一天两者都有：优先用 session 心情（因为更细），日心情只在当日没有任何 session 心情时参与

### 3.3 计算

```
h = Σ(score_i × weight_i) / Σ(weight_i)      // h ∈ [-1, 1]
开心度 index = round((h + 1) × 50)            // 0–100
```

区间文案：

| index | 标签 |
| --- | --- |
| 0–29 | 偏低 |
| 30–49 | 有点低 |
| 50–69 | 平稳 |
| 70–84 | 不错 |
| 85–100 | 很好 |

无数据 → `null`，UI 显示「还没有足够的心情记录」。

### 3.4 对外 API（放在 `src/lib/selectors.ts`）

```ts
export interface HappinessPoint {
  date: string;            // YYYY-MM-DD
  index: number | null;    // 0-100，无数据为 null
  samples: number;         // 参与计算的心跳数（dialog 用来说明样本量）
}

export function happinessOfDay(db, date): HappinessPoint;
export function happinessRange(db, fromDate, toDate): HappinessPoint[];  // 含端点
export function happinessAverage(db, fromDate, toDate): number | null;
```

## 4. 日记：写 → 归档 → 档案

### 4.1 状态机

```
（无记录）──写──> draft ──「完成并归档」──> archived
                   ↑                          │
                   └──────「继续编辑」─────────┘
```

- `draft`：编辑器可写，自动保存（沿用现有 800ms 防抖）
- `archived`：只读档案视图，显示标题、正文（排版态）、心情、当日专注摘要、标签、归档时间
- 「继续编辑」把 `status` 置回 `draft`，保留 `archivedAt` 作为历史

### 4.2 界面

**写（`/journal/:date`，draft）**
- 顶部：日期 + 心情 + 状态徽章（草稿）
- 主体：编辑 / 预览分栏（现有能力保留）
- 右上主按钮：**完成并归档**（唯一 primary）
- 底部：字数、保存状态

**档案（同路由，archived）**
- 顶部：日期 + 心情 + 「已归档 · 时间」
- 主体：单栏阅读排版（`max-width: 68ch`），不再显示编辑框
- 操作：继续编辑（soft）、导出该篇（ghost）

**日记库（`/journal/library`，新增路由）**
- 卡片列表，按日期倒序，每张卡：日期、心情、标题/首行、字数、专注分钟
- 筛选：全部 / 有心情 / 已归档 / 草稿
- 搜索：标题 + 正文（前端 `includes`，数据量小）
- 多选 → 批量删除（带撤销）
- 空状态：几何构成 + 「今天想写点什么吗」

### 4.3 路由

`App.tsx` 增 `/journal/library`，其余不变。

## 5. 删除与整理

### 5.1 可撤销删除

统一交互：删除 → 底部滑入撤销条「已删除 N 项 · 撤销」→ 6 秒后自动确认。

支持删除：
- 单条番茄记录（当日详情里）
- 单篇日记（日记库 / 档案页）
- 批量（日记库多选）

技术：先本地移除并保留副本，超时后真正持久化删除；撤销则原样插回（保持 id 不变）。

### 5.2 设置页「数据整理」

| 功能 | 说明 |
| --- | --- |
| 按范围清空 | 近 7 天 / 本月 / 全部（二次确认，输入「删除」才可点） |
| 一键压缩 | 合并同日多条同任务 session？**不做**（会破坏原始记录） |
| 导出备份 | 沿用现有 JSON 导出，清空前强制提示先导出 |

## 6. 动效规范

| 场景 | 时长 / 曲线 | 说明 |
| --- | --- | --- |
| 开心度数字 | 800ms easeOutCubic | 0 → 目标值滚动，`tabular-nums` |
| 开心度弧线 | 900ms `cubic-bezier(.16,1,.3,1)` | `stroke-dashoffset` 绘制，颜色随区间渐变 |
| 数值变化脉冲 | 420ms | 弧线光晕闪一次（复用 `ring-flash` 思路） |
| 心情选择 | 200ms | 选中：上浮 2px + 外环 4px + 轻微 scale(1.06) |
| 日记归档 | 320ms | 卡片轻微上移 + 透明度 + 「已归档」徽章 fade-in（不做翻页作弊动画） |
| 删除一行 | 260ms | 高度折叠 → 其余行 FLIP 归位 |
| 撤销条 | 220ms | 从底部 `translateY(12px)` 滑入 |
| 列表进入 | 每项 40ms stagger，总时长 ≤ 240ms | 只做前 6 项，避免长列表拖沓 |
| 页面切换 | 已有 View Transition | 不改 |

统一约束：只动 `transform` / `opacity` / `height`（折叠时）；全部受 `prefers-reduced-motion` 控制。
