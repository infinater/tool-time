# 番茄日历 · 审美提升计划 v1

> 目标：把当前"能跑"的界面，提升到"愿意每天打开"的水平。
> 约束：**不改信息架构、不加功能、不换 UI 框架**，只动视觉语言与细节。
> 配套可点开的效果试样：`design/style-tile.html`（两套方向 A/B 可切换）

---

## 1. 先说结论

当前界面是典型的**工程师审美**：结构清楚、能用，但缺三样东西——**层次、节奏、克制**。

具体表现为：所有卡片都是同一个 1px 描边 + 16px 圆角；字号只有 4 档；颜色只有"强调色 vs 灰"；动效只有一个 220ms 淡入。于是屏幕看起来很"平"，用户不知道先看哪里。

**改造思路不是"加点渐变和圆角"，而是建立一套可复用的视觉语言**（token → 组件 → 页面），让后续每加一个功能都自动好看。

推荐方向：**A 暖中性极简**（详见 §3）。

## 2. 现状诊断（逐条对应代码，不空谈）

| # | 问题 | 现在的实现 | 造成的观感 |
| --- | --- | --- | --- |
| D1 | 层级只靠描边 | 卡片统一 `border border-line`，`surface #17181d` 与 `elevated #1d1f25` 只差 6 级亮度 | 所有块一样重，眼睛没有落点 |
| D2 | 字号阶梯断裂 | 12/13/14/24 四档，正文 14px、次要信息 11px | 中文 11px 在 125% 缩放下发虚；标题与正文之间没有中间层 |
| D3 | 间距无节奏 | `p-4 / p-5 / px-8` 混用，卡片内边距 20px 而格子间隙 4px | 呼吸感不均，密的地方挤、疏的地方空 |
| D4 | 圆角一刀切 | 全部 16px（chip 除外） | "什么都软"，缺少硬边对比，显得像模板 |
| D5 | 图标风格混用 | 番茄用 🍅 emoji，心情用 emoji，功能图标用 lucide | 两种语言打架，深色下 emoji 边缘发脏 |
| D6 | 热力图用透明度 | `color-mix(accent 10%/22%/38%)` | 深色底上低档几乎不可见、高档偏"泥"，色相不干净 |
| D7 | 心情点与热力抢戏 | 心情点 2px、日记点 1.5px、格子 74px | 信息密度高但主次不清 |
| D8 | 图表是"玩具感" | 无基线、无网格、柱宽随容器拉伸 | 数据感弱，不像可信的记录工具 |
| D9 | 状态变化无反馈 | 只有页面 `fade-up`；暂停/完成/保存都是瞬变 | 操作"没有回应"，削弱专注感 |
| D10 | 长文阅读没行长控制 | 日记预览宽度跟随容器 | 宽屏下一行 100+ 字，读起来累 |

**结论**：D1–D4 是系统性问题（token 层），D5–D10 是组件层。先改 token，组件改造会顺带变好。

## 3. 三个方向（选定一个再动手）

### A. 暖中性极简 —— **推荐**

- 关键词：暖灰底、单一强调色、靠留白分层、几乎没有装饰
- 参照：Things 3（结构）、Linear（克制）、Raycast（细节密度）
- 优点：耐看、白天黑夜都稳、改造成本最低（主要是 token）
- 风险：容易做成"另一个灰软件"，需要靠排版和动效拉开差距
- 适合：每天用 2 小时以上的工具型产品

### B. 纸感编辑

- 关键词：米白纸面、衬线标题、大留白、墨色正文
- 参照：iA Writer、Are.na、Kinfolk 式排版
- 优点：日记模块会非常出彩，情绪价值高
- 风险：番茄钟是"计时工具"，纸感会削弱紧迫感；深色模式难做
- 适合：日记为主、专注为辅的产品定位

### C. 数据仪表

- 关键词：高对比、信息密集、网格清晰、等宽数字
- 参照：GitHub 贡献图、Vercel Dashboard、Grafana（精简版）
- 优点：统计页会很有说服力
- 风险：日常打开会显得"上班"，心情/日记模块会违和
- 适合：复盘型用户、量化自我爱好者

**建议**：**A 为骨架，B 取 20%（日记正文用衬线可选项），C 取 10%（统计页数字用等宽、加基线）**。这样既统一又不单调。

## 4. 设计原则（写进代码注释，评审时逐条对照）

1. **一屏一个焦点**：专注时屏幕上只允许圆环是"亮"的，其他一律退到 `sub` 层。
2. **层级靠明度与留白，不靠描边**：能用一个背景差解决，就不加线。
3. **颜色只表语义**：accent 只给"正在发生的动作"和"今天"，装饰一律中性。
4. **中文优先排版**：以中文 x-height 校准字号与行高，最小 12px，正文 15px/1.75。
5. **动效只解释因果**：状态变了才有动画，时长 ≤ 320ms，不做装饰性循环。

### 5.2 强调色（番茄红，只做语义）

| Token | Dark | Light | 用途 |
| --- | --- | --- | --- |
| `--accent` | `#e8674c` | `#d4523a` | 主按钮 / 进行中 / 今天 |
| `--accent-hover` | `#f0785f` | `#c04730` | hover |
| `--accent-weak` | `#2a1a16` | `#fbe9e4` | 浅底（选中态） |
| `--accent-text` | `#ff9a82` | `#a83c28` | 红字（对比度 ≥ 4.5:1） |

| --- | --- | --- |

| 2（30–90m） | `#5c2f28` | `#eeb6a9` |

### 5.3 字体

| 角色 | 字体栈 | 字号/行高/字重 | 字距 |
| --- | --- | --- | --- |
| Display（页面大标题） | Inter + 系统中文 | 28 / 1.25 / 600 | -0.02em |
| H2（区块标题） | 同上 | 20 / 1.35 / 600 | -0.01em |
| H3（卡片标题） | 同上 | 15 / 1.4 / 600 | 0 |
| Body | 同上 | 15 / 1.75 / 400 | 0 |
| Body-S | 同上 | 13 / 1.6 / 400 | 0 |
| Caption | 同上 | 12 / 1.5 / 500 | 0.01em |
| 数字（计时/统计） | `ui-monospace`, `JetBrains Mono`, `Consolas` | 56 / 1 / 500，`tabular-nums` | -0.03em |
| 日记正文（可选） | `LXGW WenKai`（OFL）/ `Georgia` 回退 | 16 / 1.9 / 400 | 0 |

- 中文字体：**不打包**微软雅黑（授权问题），用系统栈 `"Microsoft YaHei UI", "PingFang SC", "Noto Sans SC"`。
- 若要更统一，可打包 `思源黑体`（OFL）子集，代价 +2MB。
- 日记用衬线是**可选项**（设置 → 外观），默认关，符合方向 B 的 20%。

### 5.4 间距 / 圆角 / 描边 / 阴影

| 项 | 值 |
| --- | --- |
| 间距（4pt 网格） | 4 / 8 / 12 / 16 / 24 / 32 / 48 |
| 卡片内边距 | 24（大卡）/ 20（中卡）/ 16（列表项） |
| 圆角 | 控件 8 / 卡片内元素 10 / 卡片 14 / 弹窗 18 / chip 999 |
| 描边 | Dark **不用**描边，用 `--n-2` 面 + 顶部 1px 高光 `rgba(255,255,255,.04)` |
| 描边（Light） | 1px `--n-3`，配 `0 1px 2px rgba(0,0,0,.04)` |
| 阴影 | Dark 只在弹窗用 `0 24px 60px -12px rgba(0,0,0,.6)`；Light 卡片 `0 1px 3px rgba(0,0,0,.05)` |

> 圆角不再统一 16，而是按"控件 < 容器 < 弹窗"递增，形成**软硬对比**（D4 的解法）。

### 5.5 动效

| 场景 | 时长 | 曲线 | 属性 |
| --- | --- | --- | --- |
| hover / focus | 120ms | `cubic-bezier(.4,0,.2,1)` | background, border, color |
| 状态切换（暂停↔运行） | 180ms | `cubic-bezier(.34,1.2,.64,1)` | scale 1→1.02→1 |
| 面板进入（结束面板） | 260ms | `cubic-bezier(.16,1,.3,1)` | opacity + translateY(8px) |
| 圆环进度 | 500ms linear | — | stroke-dashoffset |
| 完成瞬间 | 320ms | `cubic-bezier(.34,1.56,.64,1)` | 圆环描边闪一次 accent |
| 页面切换 | 200ms | ease-out | opacity 0→1（去掉位移） |

> 原则：**位移幅度 ≤ 8px**，不做弹跳（bounce），不做无由头的呼吸动画（只在 running 时给圆环一层 4s 的极淡光晕，透明度 ≤ 0.12）。

## 6. 组件级改造清单（before → after）

### 6.1 番茄圆环（最该改的一个）

| 项 | Before | After |
| --- | --- | --- |
| 尺寸 | 248px，描边 10 | 260px，进度 12、底环 2（**粗细对比**代替同宽） |
| 刻度 | 无 | 外圈 60 格刻度线，每分钟一格，已完成区变 accent |
| 数字 | `font-mono 48px` | 56px，`tabular-nums`，字重随剩余时间轻微变化（<1min 变 600） |
| 状态 | 文字"保持专注" | running：圆环外 4s 呼吸光晕（≤0.12）；paused：进度环降为 40% 不透明 + 中央显示"已暂停" |
| 完成 | 直接弹窗 | 圆环闪一次（320ms），再弹窗 |

### 6.2 按钮（三层足够）

- `primary`：实心 accent，只在"开始专注 / 保存"出现，**一屏最多一个**
- `soft`：`--n-2` 面 + 无描边（dark），用于次要动作
- `ghost`：无底色，hover 才出面，用于图标按钮
- 焦点环：`outline: 2px solid accent/40; outline-offset: 2px`，**键盘可见、鼠标不可见**（`:focus-visible`）

### 6.3 卡片

- Dark 去掉描边，改 `background: --n-1` + `box-shadow: inset 0 1px 0 rgba(255,255,255,.04)`
- 卡片标题上一行加 8px 间距，与内容区用 `--n-2` 细线（仅 1px、透明度 40%）分隔
- 大卡内边距 24，内容块间距 16（现在 20/12 混用）

### 6.4 日历（信息密度重排）

| 项 | Before | After |
| --- | --- | --- |
| 格子 | 74px，热力铺满整格 | 84px，热力缩为**底部 3px 色条**（不占背景），减少花 |
| 数字 | 12px，今天=实心红块 | 13px/500，今天=**红字 + 上标小点**（不用填充块） |
| 心情 | 2px 圆点右上 | 3px 圆点右上，颜色用 5 档语义色；悬停显示 emoji |
| 日记角标 | 1.5px 灰点 | 改为右下角 2px 短竖线（与心情点形状区分） |
| 选中 | accent 描边 | `--n-3` 背景 + 1px accent 内描边 |
| 月摘要 | 4 个 chip 横排 | 改为一行文字 + 分隔符，数字加粗，去 chip 边框 |

> 逻辑：**一格里只允许两个视觉信号**（数字 + 热力），心情和日记用"形状不同的小标记"，避免三个点打架（D7）。

### 6.5 心情选择

- 现在：5 个 emoji 圆形按钮，选中放大 1.05
- 改：**5 个色环 + 文字标签**（很糟/低落/一般/不错/很好），选中态 2px 外环 + 轻微上浮 2px
- 设置里保留"表情模式"开关（emoji 仍是很多人的偏好）

### 6.6 日记

- 编辑区：行高 1.9，最大宽 `68ch`，`caret-color: accent`，选中文字 `accent/25`
- 预览：H1/H2 用 `Display` 字重，正文可选衬线；引用块改左侧 2px accent + 缩进 16，去掉斜体（中文斜体丑）
- 顶部工具栏：按钮从 6 个降到 4 个（模板 / B / 代码 / 预览），其余收进 `⋯`
- 保存状态：从文字改"小圆点 + 时间"，保存中为呼吸点

### 6.7 图表

- 去掉容器描边，柱形宽 8px、圆角 3px、间距 6px
- 加 0 基线与 25/50/75% 三条极淡网格线（dark 用 `--n-3`）
- 悬停：整列背景微亮 + 顶部浮出数值
- 数字统一 `tabular-nums`，单位移到轴尾而不是标题括号

### 6.8 空状态与微文案

- 空状态统一为"几何构成"插图（3–4 个圆/线，accent 10%），不引第三方插画库
- 文案保持中性，不用"加油/你还差一点"
- 加载态用骨架（2 行），不用转圈

### 6.9 图标

- 全站只用 **lucide**，`stroke-width: 1.75`，尺寸 16/18 两档
- 番茄 logo 换成矢量（与 `icon.ico` 同一图形），emoji 只保留在心情的"表情模式"里

## 7. 无障碍与 Windows 细节（容易被忽略但很影响"精致感"）

| 项 | 要求 |
| --- | --- |
| 对比度 | 正文 ≥ 4.5:1，大字 ≥ 3:1；`--n-7` 只用于 12px 以上的次要信息 |
| 最小字号 | 12px（中文在 100% 缩放下 11px 会糊） |
| 缩放 | 125% / 150% 下不裁切、不重叠（日历格子用 `min-h` 而非固定高度） |
| 焦点 | 所有键盘可达元素有可见焦点环，Tab 顺序与视觉顺序一致 |
| 字体渲染 | 不关闭 `-webkit-font-smoothing`；深色下避免纯白文字（用 `--n-10`） |
| 减少动效 | 尊重 `prefers-reduced-motion`，动效降为 0ms |

## 11. 明确不做

- 不引入新的 UI 组件库（继续 shadcn 风格手写 + Tailwind）
- 不引入动效库（framer-motion 等），CSS transition 足够
- 不做插画/3D/大图背景
- 不改信息架构、不挪功能位置、不加新功能
- 不在这一轮做响应式（Windows 单端，最小 960px 宽）
